### Instalar vite
```
 npm create vite@latest .
```

### Instalar axios, lucide-react e react-router-dom
```
npm i axios lucide-react react-router-dom
```

### Instalar Tailwindcss
```
npm install tailwindcss @tailwindcss/vite
```

### Instalar react-router
```
npm i react-router
```
